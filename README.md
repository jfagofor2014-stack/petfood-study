# ペットフード販売士 学習アプリ

ペットフード販売士認定試験の受験者向けの学習用 PWA（Progressive Web App）。
専門テキストを1文ずつ読み上げ、中断した位置から再開できる。節・章・苦手順の
確認テストで復習もできる。

## 試験について

| 項目 | 内容 |
|---|---|
| 主催 | 一般社団法人ペットフード協会 |
| 形式 | CBT・四肢択一式 25問／60分 |
| 出題範囲 | 専門テキストの全範囲（全10章85節・154ページ） |
| 合格基準 | 非公開 |

## 機能

- 4つのタブ：**きく**（読み上げ）／**もくじ**／**テスト**／**設定**
- テキストの読み上げ（1文ずつ、速度 0.5〜2.0倍、一時停止、1文単位で前後に移動、
  文をタップしてそこから再生）
- 読んでいる文のハイライト表示
- 中断した位置を文が終わるたびに自動保存し、「前回の続きから」で再開
- 節ごと・章ごと・苦手順の4択確認テスト。成績を記録し、間違えた問題から
  本文の該当箇所へジャンプできる
- 本番形式の模擬試験（全章から25問・60分・四肢択一、中断と再開、章別の正誤）
- オフライン起動、ホーム画面への追加に対応した PWA

テスト機能に出る問題は**公式の過去問ではなく**、テキストの範囲から作成した
予想問題（アプリ内にもその旨を表示している）。

## 教材データについて

**このリポジトリに教材データ（テキスト本文）は含まれていない。**
テキストは一般社団法人ペットフード協会の著作物であり、再配布できないため。

利用するには、自分の手元のテキストから教材ファイル `petfood-data.json` を
作り、アプリの初回起動画面（取り込み画面）で選ぶ。作り方は
[tools/README.md](tools/README.md) を参照。OCR・校正・組み立ての3段階の
手順が書かれている。

教材データは端末の IndexedDB にのみ保存され、ネットワークには送信されない。

## 使い方

1. Android Chrome で `https://jfagofor2014-stack.github.io/petfood-study/` を開く
2. 教材ファイル（`petfood-data.json`）を選ぶ
3. メニューから「ホーム画面に追加」しておくと、次回からアイコンから起動できる

## 動作環境

Android Chrome を想定している（開発・確認は Pixel 8a）。

**Android Chrome は画面が消えると読み上げが止まる。** バックグラウンド再生は
できない。この対策として、設定の「再生中は画面を消さない」（Wake Lock）が
既定でオンになっている。オンのままであれば、再生中に画面が自動で消えることはない。

## 開発

```bash
npm test                      # ユニットテスト（node --test、130件）
python3 -m http.server 8765   # ローカルで動かす（http://localhost:8765/）
```

ビルドステップはない。外部ライブラリも使っていない（`package.json` の
`dependencies` は空）。ブラウザで直接読み込めるバニラ JavaScript（ES Modules）。

## ディレクトリ構成

| ディレクトリ | 中身 |
|---|---|
| `index.html` / `css/` | 画面の骨格とスタイル |
| `js/app.js` | 画面の切り替えなどアプリ全体の起点 |
| `js/lib/` | 純粋ロジック（book / db / html / progress / quizpick / quizresults / schema / sentences / settings / speech / wakelock）。すべてテストがある |
| `js/views/` | 4タブ＋取り込み画面（onboarding / player / toc / quiz / settings）の DOM 描画 |
| `sw.js` / `manifest.json` / `icons/` | PWA（オフライン動作・ホーム画面追加） |
| `test/` | `node --test` によるユニットテスト |
| `tools/` | 教材データ（`petfood-data.json`）を手元のテキストから作るスクリプト（`ocr.py` / `build_data.py`）。詳細は [tools/README.md](tools/README.md) |
| `docs/superpowers/` | 設計書・実装計画 |

## 運用上の注意

アプリのファイル（`index.html` / `css/` / `js/` / `manifest.json` / `icons/`）を
追加・変更したら、`sw.js` の `ASSETS`（キャッシュ対象一覧）と `CACHE`（版番号）を
更新すること。更新しないと、古いキャッシュが残ってしまい変更が反映されない。
