# フラッシュカード 設計書

作成日: 2026-09-30
対象: ペットフード販売士 学習アプリ（`/Users/taichi/petfood-study`）
前提となる設計書: `2026-09-15-petfood-study-design.md` / `2026-09-22-mock-exam-design.md`

## 1. 背景

初版の設計書がスコープ外とした「フラッシュカード画面。同じく問題データを流用できる形にしておく」を作る。

教材は全10章82節・2,533文・図表28点・**問題219問**（全82節に問題がある）。
既存の学習手段は3つある。

| | 形式 | 鍛えるもの |
|---|---|---|
| きく | 本文の読み上げ | 通読・耳からの定着 |
| テスト | 4択・即時採点 | **再認**（選択肢を見て正解を選べる） |
| 模擬試験 | 25問60分・最後に採点 | 本番の通し演習 |

**再生（何も見ずに思い出せる）を鍛える手段が無い。** 4択は選択肢がヒントになるため、
「見れば分かるが思い出せない」状態を素通りしてしまう。この試験は数値・項目数・専門用語が多く、
再認だけでは足りない。

## 2. 方針

**既存の219問をそのままカードにする。新しい教材は作らない。**

- **表**: 問題文だけ。**選択肢を出さない**。これが再認と再生を分ける一点である
- **裏**: 正解の選択肢・解説・章とページ・「この節を読む」

利用者は表を見て頭の中で答えを出し、めくって答え合わせをする。
採点は**自己申告**（「わかった」「あやしい」）とする。自由記述を照合する仕組みは作らない。

「あやしい」にしたカードは**山の最後に戻し、全部「わかった」になるまで回す**。
1周して終わりではなく、覚えるまで繰り返す形にする。

自己申告は既存の成績（`pfs:quiz`）に記録する。「わかった」＝正解、「あやしい」＝不正解として扱い、
**そのまま「苦手な問題を解く」に流れる**。テスト・模試・カードの3つが同じ成績を共有する。

### 作らないもの

- 間隔反復（SM-2 等の復習日スケジューリング）。日付をまたぐ復習計画は、
  受験まで日数が限られるこの用途では過剰。まず「覚えるまで回す」で十分
- 自由記述の入力と照合
- カードの自作・編集
- 読み上げ（カードは目で見るもの。耳から入れるのは「きく」の役目）

## 3. 出題の選び方

既存の `js/lib/quizpick.js` をそのまま使う。新しい抽出ロジックは作らない。

| 選び方 | 枚数 | 使う関数 |
|---|---|---|
| 苦手なカード | 20 | `pickWeak(questions, results, 20)` |
| 章まとめ | その章の全問 | `pickForChapter(questions, chapterNo, n)` |
| 節ごと | その節の全問 | `pickForSection(questions, sectionId, n)` |

章・節は**全問**を出す。テスト画面は章10問・節5問に絞っているが、
カードは覚えるための反復なので取りこぼしを作らない。

## 4. 山（デッキ）の進み方

`js/lib/flashcards.js` に純粋ロジックとして閉じ込める。DOM も storage も触らない。

```js
createDeck(cards) -> {
  current(), size(), remaining(), doneCount(), againCount(), isDone(),
  known(), unsure()
}
```

- `queue` の先頭が今のカード
- `known()` … 先頭を山から抜き、覚えた集合に入れる
- `unsure()` … 先頭を**山の最後へ回す**。覚えた集合には入れない
- `isDone()` … 山が空になったとき
- `againCount()` … 「あやしい」を押した延べ回数。終了画面で「1回で覚えた枚数」を出すのに使う
- 同じカードを二度「わかった」にはできない（山から消えるため）

山が1枚だけのときに `unsure()` を押すと同じカードが再び先頭に来る。
これは仕様どおりで、覚えるまで回す形と一貫している。

## 5. 画面

入口は**テストタブ**の模擬試験の下に置く。タブは増やさない（スマホで窮屈になるため）。
模試と同じく独立画面（`flash`）として `app.js` に登録し、タブバー上は「テスト」を選択中に見せる。

### 5.1 メニュー（`menu`）

- 見出しと説明: 「選択肢を見ずに思い出す練習です。覚えるまで繰り返します。」
- 「苦手なカードを覚える（◯枚）」
- 章まとめ（10章ぶん、各章の枚数つき）
- 節ごと（82節ぶん、各節の枚数つき）
- 「テストに戻る」

### 5.2 カード（`card`）

上部: 「◯ / ◯ 枚」と進捗バー、「あと◯回」（`againCount`）

**表**: 問題文のみ。**選択肢・正解・解説・章・ページを一切出さない。**
下部に「答えを見る」。

**裏**: 正解の選択肢／解説／第◯章（p.◯）／「この節を読む」。
下部に「わかった」「あやしい」の2ボタン。

「答えを見る」を押すまで裏の内容を DOM に入れない。

### 5.3 終わり（`result`）

- 「◯枚を覚えました」
- 「1回で覚えた枚数 ◯ / ◯」（`size - againCount` ではなく、`unsure` を一度も押さずに
  `known` にしたカードの数。`againCount` は延べ回数なので別に数える）
- 「もう一度」「テストに戻る」

## 6. 永続化

**カード専用の保存はしない。** 自己申告は `quizResults.record(id, ok)` に流すだけ。
途中でやめた場合、その山は保存せず消える。模試と違い時間の制約が無く、
いつでも同じ条件で作り直せるため。

## 7. エラー処理

| 状況 | ふるまい |
|---|---|
| 教材に問題が1問もない | メニューに案内を出し、ボタンを出さない |
| 苦手なカードが0枚 | そのボタンを無効にする |
| 問題が0問の章・節 | メニューに出さない |
